# My House — умный дом с альтернативными источниками питания

Десктопное приложение на **Python + PyQt5** для управления устройствами умного дома,
который питается от солнечных панелей и аккумулятора.

## Скачать для Windows

1. Откройте раздел **[Releases](https://github.com/slavik2360/My_house/releases/latest)**.
2. Скачайте **`SmartHome.exe`** и запустите его — установка и Python не нужны.

> Windows SmartScreen может показать предупреждение «Неизвестный издатель» (файл не подписан).
> Нажмите **«Подробнее» → «Выполнить в любом случае»**.

## Возможности

- **Вход и регистрация**, у каждого пользователя свой дом.
- **Солнечная энергосистема**: панели 6 кВт, аккумулятор 30 кВт·ч, симуляция суток с облачностью,
  поток энергии «панели → АКБ → дом → сеть», ускорение времени.
- **Энергия**: график за сутки, экономия в тенге, CO₂, эко-режим (отключение второстепенных нагрузок
  при низком заряде), работа зарядки авто и бойлера только от излишков солнца.
- **Каталог из 129 моделей** в 49 типах устройств: освещение, климат, кухня, безопасность, датчики и т.д.
- **Управление устройствами**: яркость и цвет ламп, термостат кондиционера и обогревателя (температура
  в комнатах моделируется), анимированный чайник, видео с камер, робот-пылесос, стиральная машина,
  таймеры и сценарии.
- **План дома** с устройствами на планировке и **журнал событий** с уведомлениями.

## Запуск из исходников

```bash
python -m venv env
source env/bin/activate        # Windows: env\Scripts\activate
pip install -r requirements.txt
python home.py
```

Для быстрой отладки вход без пароля включается флагом `SKIP_AUTH = True` в начале `home.py`.

## Сборка

Каждый push в `main` собирает `SmartHome.exe` через GitHub Actions (вкладка **Actions** → артефакт).
Чтобы опубликовать новую версию в Releases, создайте тег:

```bash
git tag v1.0.1
git push origin v1.0.1
```
